An interactive narrative and intelligence index for a proposed island network spanning Bribie Island, Moolgumpin, Minjerribah and the Southern Moreton Bay Islands. It adapts a set of Minjerribah-focused concepts into a wider regional frame for discussion.

## Public page

[Explore the live Archipelago index](https://auraofintelligence.github.io/Archipelago/).

## What is here

The dashboard lets visitors:

- switch between island geographies;
- filter an embedded 19-record concept index by narrative, economy, technology and community themes;
- compare illustrative readiness profiles; and
- explore summaries covering media, local economies, resilience, digital tools and community wellbeing.

Open `index.html` in a browser for a local view. The page has no build step, but loads Tailwind CSS, Chart.js and fonts from external services.

## Status and boundaries

This is a concept index, not a current regional plan or evidence database. The 19 records are embedded summaries; the source documents they describe are not supplied in this repository. Chart values are illustrative and must not be treated as measured community readiness.

Nothing here confirms community demand, cultural authority, partnership, funding, site control, approvals or delivery readiness on any island. Those matters remain to be tested with the relevant communities, Traditional Owners, councils and other authorities.
